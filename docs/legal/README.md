# Legal documents

The canonical Privacy Policy and Terms of Service live in
[`web/content/legal/`](../../web/content/legal/) (`privacy.md`, `terms.md`) so
the web app can render them at `/privacy` and `/terms`.

They are **first drafts** — every `[PLACEHOLDER]` needs filling in, and both
should be reviewed by a lawyer before launch. See `docs/LAUNCH.md` §5.

Placeholders to resolve: publishing entity + address, contact/privacy email,
Azure region, retention periods, minimum age, jurisdiction/venue, effective
date, liability cap.
